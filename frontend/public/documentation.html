ABSTRACT

College Placement Management System is web-based app designed to digitize placement info. Traditional methods (Excel, WhatsApp, Email) lead to duplicate records, delayed updates, lack of real-time visibility into Selected/Rejected status.

Proposed system uses MERN: MongoDB Atlas stores users, companies, applications; Express/Node provides RESTful APIs for JWT auth, company management, application tracking with status enum Applied/Selected/Rejected; React + Vite + Tailwind provides responsive UI deployed on Vercel at live link. Implements Student role (register, login, view jobs, apply, track status with color Green Selected, Red Rejected, Yellow Applied) and Admin role (post companies, view students, view applications, update status via Select/Reject). Flow Student Apply -> Admin Select/Reject -> Student sees real-time answers viva: Does project show if students selected or rejected? YES through Applications status field.

INTRODUCTION

Campus placement connects students with employers. Placement cell maintains records, manages visits, publishes JDs, handles deadlines, tracks applications, records outcomes selected/rejected. Manual management causes outdated inconsistent data. Purpose: Design, develop, deploy full-stack web app simplifying coordination, improving accessibility, providing clear visibility with real-time status. Scope: React + Vite + Tailwind frontend, Node/Express backend API, MongoDB Atlas with 3 collections (Users, Companies, Applications), student/admin workflows, company management, application submission, status tracking Applied/Selected/Rejected, deployment on Vercel with auto-deploy from GitHub, JWT + bcrypt, testing live.

PROBLEM & OBJECTIVES

Problems: Duplicate Excel, lost WhatsApp announcements, no centralized view of who applied where, no systematic Selected/Rejected display causing confusion, excessive coordinator time, no live portal.

Objectives: (1) Centralize data in Atlas (2) React UI for jobs (3) Admin maintains company records (4) Application tracking status Applied/Selected/Rejected (5) Admin Select/Reject buttons PUT API (6) Student real-time Green/Red/Yellow (7) Live on Vercel (8) Modular MERN maintainable.

SYSTEM DESIGN

Architecture: Presentation: React Vite Tailwind + Router + Axios. API: Node Express + JWT middleware + RBAC. Data: MongoDB Atlas Users, Companies, Applications. Deployment: Vercel frontend auto-deploy + Atlas.

Flow: User -> React (Vercel) -> Axios + JWT -> Express API -> Mongoose -> Atlas -> JSON Response -> React State -> UI Re-render.

Student Apply: Click Apply -> POST /api/applications {companyId} + JWT -> Backend checks duplicate, creates Application status Applied -> Save Atlas. Admin Select: Click Select -> PUT /api/applications/:id {status: Selected} + admin JWT -> Verify admin role, updates status -> Save. Student Checks: GET /api/applications/my + JWT -> Finds where studentId = userId, populate company, returns list -> Shows status badges.

EXECUTION STEPS

Step 1 - Open Live Link: Input URL https://college-placement-management-one.vercel.app -> Output: Login page loads - Production live

Step 2 - Register: Input Name, Email, Password, Department -> Click Register. Execution: POST /api/auth/register -> bcrypt hash -> Save to Atlas Users -> Success. Output: Account created

Step 3 - Login: Input Email, Password -> Click Login. Execution: POST /api/auth/login -> Find user -> Compare bcrypt -> Generate JWT token -> Return token. Output: Token stored in localStorage, redirect to Dashboard

Step 4 - View Jobs & Apply (Student): Input Click Apply button. Execution: GET /api/companies -> Display cards, POST /api/applications {companyId} + JWT -> Check duplicate, Create Application status Applied -> Save Atlas. Output: Applied Successfully

Step 5 - Update Status (Admin) - CRITICAL: Input Admin login, View All Applications, Click Select or Reject. Execution: GET /api/applications/all + admin JWT, PUT /api/applications/:id {status: Selected} + admin JWT -> Verify admin role, Update status field Applied to Selected/Rejected -> Save Atlas. Output: Admin table status changes, Student My Applications shows Green Selected or Red Rejected on refresh

Step 6 - Deployment Execution: GitHub push main -> Vercel auto-detects -> npm install -> npm run build (Vite) -> Build Successful -> Deploy Production -> Live at link. MongoDB Atlas: Cluster connected, Collections verified
