# College Placement Management Portal

*Live Demo:* https://college-placement-management-one.vercel.app
*GitHub Repo:* https://github.com/bindusadhana238-droid/college-placement-management

## About The Project
This is a full-stack College Placement Management System built with MERN Stack. It helps students to apply for placement drives and helps TPO/Admin to manage companies and student applications efficiently.

## Key Features
- Student Module: Registration, Login, View Jobs, Apply, Track Status
- Admin/TPO Module: Add Companies, Manage Drives, View Applicants
- Secure Authentication using JWT
- Fully Responsive UI

## Tech Stack
- Frontend: React.js, Vite, Tailwind CSS, Axios
- Backend: Node.js, Express.js
- Database: MongoDB Atlas
- Deployment: Vercel (Frontend), Render (Backend)

## How to Run Locally
Clone the repo: git clone https://github.com/bindusadhana238-droid/college-placement-management
Frontend: cd frontend -> npm install -> npm run dev
Backend: cd backend -> npm install -> npm start
